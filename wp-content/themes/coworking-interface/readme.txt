== Description ==

Coworking Interface is a modern and flexible multipurpose business WordPress theme designed for companies, agencies, startups, consultants, and professionals across a wide range of industries. It includes thoughtfully crafted starter designs tailored to different business niches, helping you build a professional website with minimal effort. With responsive layouts, intuitive customization options, and compatibility with the latest WordPress features, Coworking Interface makes it easy to create a fast, polished, and user-friendly website without requiring any coding experience.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

== Frequently Asked Questions ==

= Does this theme support any plugins? =

Coworking Interface includes support for WooCommerce and for Infinite Scroll in Jetpack.
